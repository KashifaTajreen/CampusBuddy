# Generated results (local only)

Test runners create JUnit XML, browser reports and verification JSON here.
These outputs are ignored, not reusable fixtures. They may contain local paths,
source identifiers or private evidence and must not be committed. Public,
sanitized verification summaries belong in `docs/verification.md`.

Downloaded assets and disposable workspaces belong in ignored `.scratch/`;
original uploads/databases remain in ignored `data/`. Do not remove those
directories as a routine Git cleanup operation.
